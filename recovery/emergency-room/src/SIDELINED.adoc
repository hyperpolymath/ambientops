= Emergency Room — zig Implementation SIDELINED
:toc:

== Status

The zig implementation of emergency-room (`src/`) is *sidelined*
as of 2026-04-12 following the estate-wide zig ban (2026-04-10).

== Migration Target

The replacement is a **Gleam / Rust** implementation. Target: `src-gleam/`.

[cols="1,1"]
|===
| V module (sidelined) | Migration target

| `main.v`             | Gleam supervisor entrypoint
| `incident.v`         | Gleam `incident` module
| `capture.v`          | Gleam `capture` module
| `handoff.v`          | Gleam `handoff` module
| `backup.v`           | Rust S3/object-store crate
| `boot_guardian.v`    | Gleam / Rust systemd watchdog
| `shutdown_marshal.v` | Gleam / Rust SIGTERM handler
| `utils.v`            | Gleam stdlib / Rust utilities
|===

Tests (`*_test.v`, `integration_test.v`) should be ported as Gleam EUnit
or Rust integration tests.

The zig source is retained for reference but MUST NOT be compiled or deployed.

NOTE: As of 2026-04-17 the Zig port of `emergency-button` is complete. Matching
symlinks now live in `src/zig/` alongside these V symlinks — every `.zig` file
in `src/zig/` points into `../../../../emergency-button/src/zig/<name>.zig`.

== De-duplication note (2026-04-17)

The seven `.v` files this directory shared with `../../emergency-button/src/`
were byte-identical (1,579 LOC of duplicated source). They have been
replaced with relative symlinks pointing into `emergency-button` so
both locations stay in lockstep automatically and there is a single
source of truth for the canonical zig implementation:

* `backup.v`
* `capture.v`
* `capture_test.v`
* `handoff.v`
* `incident.v`
* `incident_test.v`
* `integration_test.v`

are now symlinks → `../../../emergency-button/src/<name>.v`.

Files unique to recovery/emergency-room (`main.v`, `utils.v`, this
SIDELINED.adoc) remain as regular files. They are the suite-specific
glue around the standalone emergency-button tool.

If the zig source is eventually deleted (per the zig ban,
2026-04-10), delete it FROM `emergency-button/src/` first; the
symlinks here will become broken pointers and can be removed in the
same commit. Do not delete files here while leaving the canonical
copies in place — that re-introduces the duplication.

The intended architecture going forward (per the user's 2026-04-17
direction): emergency-button is the standalone installable tool.
The suite at `recovery/emergency-room` is its in-tree consumer —
it should reference and pull from emergency-button, never duplicate.
The migration to Gleam/Rust (table above) is expected to preserve
this relationship: emergency-room's Gleam supervisor will *call*
the Rust crate(s) extracted from emergency-button, not re-implement
their logic.
