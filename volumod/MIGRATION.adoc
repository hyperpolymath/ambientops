= VoluMod — V-lang Deprecated (2026-04-12)
:toc:

== Status

The V-lang implementation in `src/` is *deprecated* as of 2026-04-12
following the estate-wide V-lang ban (2026-04-10).

== Migration Target: Rust

VoluMod (cross-platform audio volume and clarity optimisation) requires
platform audio APIs not yet wrapped in the estate's Zig/Rust toolchain:

| Platform | Audio API | Rust crate |
|----------|-----------|------------|
| Linux    | PipeWire / PulseAudio | `pipewire` / `libpulse-binding` |
| macOS    | CoreAudio | `coreaudio-rs` |
| Windows  | WASAPI    | `wasapi` / `cpal` |

=== Recommended Stack

[source,toml]
----
[dependencies]
cpal         = "0.15"   # cross-platform audio I/O (covers all three above)
dasp         = "0.11"   # DSP signal processing
tray-icon    = "0.14"   # system tray (Windows/macOS/Linux)
serde_json   = "1"
clap         = { version = "4", features = ["derive"] }
----

=== Architecture Sketch

The V source implements five functional areas, each mapping to a Rust module:

[cols="1,1,1"]
|===
| V module       | Functionality                                | Rust target

| `src/engine/`  | `AudioProcessor`, `ContextManager`          | `engine.rs` using `cpal` + `dasp`
| `src/platform/`| `SystemAudioCapture` (OS-specific)           | `platform.rs` with `#[cfg(target_os)]`
| `src/processors/` | Normaliser, compressor, noise-redux, EQ, limiter | DSP chain via `dasp`
| `src/ui/`      | `TrayIcon`, `AccessibilityManager`          | `tray-icon` crate
| `src/core/`    | `AudioBuffer`                               | `cpal::Data` / custom buffer
|===
