== Feature Parity

All V features are preserved:

* `trigger` subcommand — incident bundle, diagnostics, receipt, backup, handoff
* `boot-guardian` — boot stamp file, loop detection (5 boots / 10 min window),
  PCIe link-error scan from dmesg (CC-003)
* `shutdown-marshal` — component notification (observatory/clinician/session-sentinel
  via systemctl or SIGTERM), ungraceful-shutdown tracking, clean shutdown record
* `pulse` (`oom-watch` alias) — journal-based `systemd-oomd` kill detection and memory-pressure
  notifications with dedupe/cooldown, miniKanren-style diagnostics, persistent cursor state,
  and append-only A2ML event envelopes
* PII redaction, path validation (CRIT-001/CRIT-002), atomic writes
