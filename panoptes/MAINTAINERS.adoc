=== Becoming a Maintainer

See GOVERNANCE.adoc for the process of becoming a maintainer.

==== Requirements

[arabic]
. 6+ months as a trusted contributor
. Demonstrated understanding of:
* Rust programming
* RSR compliance standards
* Security best practices
. Nomination by existing maintainer
. Approval by BDFL

=== Maintainer Responsibilities

* Review and merge pull requests
* Triage issues
* Release management
* Security response
* Uphold code quality standards
* Enforce code of conduct
