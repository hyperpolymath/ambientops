____
Discover and manage the extensive—and often hidden—configuration options
in nano and micro text editors.
____

=== The Problem

Both `+nano+` and `+micro+` have *hundreds of configuration
options*—many undocumented, hidden behind compile-time flags, or
scattered across multiple files. nano-aider exposes them all through an
interactive TUI.

=== Quick Start

[source,bash]
----
# Install via Alire (recommended)
alr get nano_aider
cd nano_aider*
alr build

# Or build from source
git clone https://github.com/hyperpolymath/nano-aider.git
cd nano-aider
gprbuild -P nano_aider.gpr -XNANO_AIDER_BUILD_MODE=release
./bin/nano-aider
----

==== Prerequisites

* *GNAT* (Ada compiler) 12.0+
* *Alire* package manager
* *ncurses* development libraries

=== Features

[width="100%",cols="41%,59%",options="header",]
|===
|Feature |Description
|*Option Discovery* |Detects all nano/micro options, including hidden
ones

|*Interactive TUI* |Browse, search, and modify settings with curses
interface

|*Profile Management* |Switch between Minimal, Developer, Writer, Power
User profiles

|*Configuration Export* |Generate valid `+.nanorc+` or `+settings.json+`
files

|*SPARK Verification* |Critical sections formally verified for
correctness
|===
