== Quick Reference: CLI Commands

[source,bash]
----
julia --project=. src/main.jl init                    # Initialize configuration
julia --project=. src/main.jl generate -e EMAIL        # Generate SSH key (default: Ed25519)
julia --project=. src/main.jl list [--verbose]         # List stored keys
julia --project=. src/main.jl info --id KEY_ID         # Show key details
julia --project=. src/main.jl validate --id KEY_ID     # Validate key pair
julia --project=. src/main.jl audit [--id KEY_ID]      # Security audit
julia --project=. src/main.jl backup [--id KEY_ID]     # Backup keys
julia --project=. src/main.jl restore --backup-path P  # Restore from backup
julia --project=. src/main.jl rotate [--auto|--all]    # Rotate keys
julia --project=. src/main.jl github --action ACTION   # GitHub integration
julia --project=. src/main.jl pqc-info                 # PQC support info
----
